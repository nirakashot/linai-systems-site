# LinAI Systems Website

Official website for LinAI Systems - AI-powered phone assistant for restaurants.

## 🚀 Live Site
[www.linaisystems.com](https://www.linaisystems.com)

## 📋 About
LinAI Systems provides an always-on, human-like AI phone assistant that helps restaurants:
- Never miss calls during peak hours
- Take accurate orders with fewer mistakes
- Reduce labor costs
- Provide 24/7 availability
- Support multiple languages

## 🚀 Getting Started

### Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/linai-systems-site.git
   cd linai-systems-site
   ```

2. Open `index.html` in your browser:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx http-server
   
   # Or simply open index.html in your browser
   open index.html
   ```

3. Visit `http://localhost:8000` (if using a server)

## 🌐 Deployment Options

### GitHub Pages
1. Push code to GitHub repository
2. Go to repository Settings → Pages
3. Select branch (main) and folder (root)
4. Save and wait for deployment
5. Your site will be available at `https://yourusername.github.io/linai-systems-site/`

### Netlify
1. Push code to GitHub
2. Connect repository to Netlify
3. Build settings:
   - Build command: (leave empty)
   - Publish directory: `/`
4. Deploy

### Vercel
1. Push code to GitHub
2. Import repository in Vercel
3. Deploy automatically

### Traditional Web Hosting
1. Upload all files via FTP/SFTP to your web host
2. Ensure `index.html` is in the root directory
3. Files should maintain the same directory structure

## 📝 Customization

### Update Content
- Edit text in `index.html`
- Modify sections by updating the HTML structure

### Change Colors
- Edit CSS variables in `css/styles.css`:
  ```css
  :root {
      --primary-color: #2563eb;
      --secondary-color: #1e40af;
      /* ... more variables */
  }
  ```

### Add/Replace Images
- Place images in `assets/images/`
- Update image paths in `index.html`

### Modify Styling
- All styles are in `css/styles.css`
- Responsive breakpoints: 768px, 480px
